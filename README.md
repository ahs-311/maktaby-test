# مكتبي الإلكتروني — نظام إدارة مكتب المحاماة

تطبيق ويب (PWA) يعمل أونلاين وأوفلاين، مع مكاتب معزولة ومزامنة بين الأجهزة عبر Supabase.

## ملفات المشروع
| الملف | الغرض |
|---|---|
| `index.html` | التطبيق |
| `mk-config.js` | رابط Supabase والمفتاح العام (أنت تعدّله) |
| `mk-cloud.js` | الدخول وحسابات المكاتب والمزامنة والعمل أوفلاين |
| `sw.js`, `manifest.json`, الأيقونات | التثبيت والعمل بدون إنترنت |
| `supabase-schema.sql` | الجداول والصلاحيات (تنفَّذ مرة واحدة) |
| `supabase-owner.sql` | تسجيل حساب المالك |
| `supabase-migration-01-subscriptions.sql` | الاشتراكات (تجربة أسبوعين) وتنبيهات المالك |
| `supabase-migration-02-permissions.sql` | فرض صلاحيات الأقسام داخل قاعدة البيانات |
| `supabase-migration-03-password-reset.sql` | دعم تغيير كلمة مرور موظف |
| `supabase-migration-04-comments.sql` | مجموعة التعليقات (المرحلة D) |
| `supabase-migration-05-drafts.sql` | مجموعة مسودات المحرر (المرحلة F) |
| `mk-editor.js` | محرر المستندات: النماذج وصحف الدعاوى، الخانات، الطباعة A4، تصدير/استيراد Word |
| `vendor/jszip.min.js` | مكتبة قراءة/كتابة ملفات docx (تعمل أوفلاين، ~97KB) |
| `mk-details.js` | نافذة تفاصيل المهمة/الموعد/الجلسة: النتيجة والتأجيل والتعليقات |
| `supabase/functions/admin-members/index.ts` | Edge Function لتغيير كلمة المرور (تُنشر من لوحة Supabase) |

## الإعداد (مرة واحدة)
1. **Supabase ← SQL Editor**: الصق `supabase-schema.sql` ثم Run.
2. **Authentication ← Providers ← Email**: عطّل **Confirm email**، واترك التسجيل مفعّلًا.
3. **Authentication ← Users ← Add user**: البريد `ali7assansa3id@maktaby.app` + كلمة مرورك + فعّل **Auto Confirm User**.
4. **SQL Editor**: نفّذ `supabase-owner.sql` (يظهر صف واحد بدور owner).
5. **Project Settings ← API**: انسخ Project URL والمفتاح العام (anon/publishable) إلى `mk-config.js`.
6. نفّذ `supabase-migration-01-subscriptions.sql` ثم `supabase-migration-02-permissions.sql` ثم `supabase-migration-03-password-reset.sql` ثم `supabase-migration-04-comments.sql` ثم `supabase-migration-05-drafts.sql` (بعد الـ schema).
7. ارفع الملفات إلى GitHub وافتح الرابط.

> لا تضع كلمة مرور المالك ولا مفتاح `service_role` في أي ملف داخل المستودع.

## كيف يعمل
- أول فتح: شاشة «إنشاء حساب مدير مكتب». المدير ينشئ المحامين والموكلين ويحدد صلاحياتهم.
- كل مكتب يرى بياناته وحساباته فقط (RLS في قاعدة البيانات).
- البيانات تُحفظ في الجهاز وتُرفع تلقائيًا عند توفر الإنترنت.
- الدخول بدون إنترنت يعمل على أي جهاز سجّل منه المستخدم دخوله مرة واحدة متصلًا.

## الاشتراكات والتنبيهات
- كل مكتب جديد: تجربة مجانية 14 يومًا. قبل النهاية بـ 7 أيام يظهر عدّاد للمدير، وبعد النهاية «عرض فقط» يومين، ثم إيقاف حتى التجديد.
- التجديد يدوي من حساب المالك (زر «تجديد» بجانب كل مكتب)، والدفع بتحويل فودافون كاش أو فوري إلى 01098848735.
- المالك يرسل تنبيهات للمديرين (للكل أو لمكتب محدد) تبقى حتى يحذفها.

## الصلاحيات
- المدير: كل شيء داخل مكتبه. المحامي والموكل: حسب الأقسام الممنوحة، وتُفرض في قاعدة البيانات نفسها.
- ربط الأقسام بالبيانات في جدول `collection_modules` ويمكن تعديله بـ SQL دون تغيير الكود.
- المحامي يرى قيوده المالية وأيام عمله فقط.

## محرر المستندات: النماذج وصحف الدعاوى (المرحلة F)
- «الصيغ والنماذج» و«صحف الدعاوى»: زر **✏️ فتح في المحرر** يفتح النص في محرر شبيه بـ Word (عناوين، غامق/مائل/تسطير، محاذاة، حجم وخط، قوائم، جداول، فاصل صفحة).
- **الخانات** مثل `{{اسم_الموكل}}` و`{{رقم_القضية}}` و`{{المحكمة}}`: اختر القضية (أو الموكل) واضغط «تعبئة الخانات». الخانة التي لا بيانات لها تبقى ظاهرة بلون مميز ولا تُملأ بفراغ، وتقدر تعدّل النص يدويًا بعد التعبئة أو تتراجع.
- **الطباعة A4** بترويسة المكتب (من «بيانات المكتب»). ترقيم الصفحات يظهر في Chrome/Edge الحديثة فقط.
- **تصدير Word (.docx)** بالاتجاه من اليمين لليسار، و**استيراد .docx** كمسودة جديدة.
- المسودات تُحفظ في مجموعة `drafts` وتتزامن، وكل حفظ ينشئ **نسخة** (حتى 15 نسخة لكل مسودة) يمكن استرجاعها.
- **حدود معروفة:** القوائم تُصدَّر كنقاط نصية (• / 1.) لا كقوائم Word حقيقية؛ الصور والرؤوس والتذييلات وTrack Changes والدمج الرأسي للخلايا لا تُستورد؛ الاستيراد/التصدير اختُبر بـ LibreOffice وليس Microsoft Word نفسه.
- ملاحظة: مولّد «صحف الدعاوى (AI)» ما زال قالبًا ثابتًا وليس ذكاءً اصطناعيًا فعليًا.

## تعديل مرفقات Word بالنسخ (المرحلة F1)
- زر «✏️ تعديل» يظهر بجانب أي مرفق `.docx` (في قائمة مرفقات القضية وفي عارض المرفقات والمستندات) لمن لديه صلاحية تعديل «المرفقات» والمكتب ليس «عرض فقط». الموكل لا يعدّل.
- **الحفظ نسخة جديدة دائمًا** باسم «الاسم (نسخة N).docx». الأصل لا يتغير ولا يُستبدل. كل نسخة سجل مرفق مستقل (`versionOf` و`versionNo` و`baseId` و`editedBy` و`editedAt`).
- الحد الأقصى **10 نسخ** لكل ملف؛ تُحذف الأقدم مع ملفها. الأصل محمي: لا يُحذف وله نسخ، لكن يُحذف مع مستنده/توكيله/قضيته.
- «سجل النسخ» في العارض وداخل المحرر. وزر «⬇️ تنزيل الأصل للتعديل في Word» مع تنبيه بأن التحويل قد يفقد تنسيقات معقدة (يظهر تنبيه تأكيد قبل أول تعديل لكل ملف على الجهاز).
- ترويسة المكتب في الملف الناتج **غير مفعّلة افتراضيًا** (خيار يدوي).
- **حد معروف:** الملفات محلية في المتصفح حتى المرحلة E؛ النسخة الجديدة ملفها على الجهاز الذي أنشأها فقط، أما بياناتها الوصفية فتتزامن. ما لا ملف له على الجهاز يظهر عليه «الملف غير موجود على هذا الجهاز» ولا يمكن تعديله.
- إصلاح ضمني: عمودا الجدول في تصدير docx كانا يُكتبان بعمود واحد في `tblGrid` (عيب قديم من F2).

## نشر دالة تغيير كلمة المرور (مرة واحدة)
1. Supabase ← **Edge Functions** ← **Deploy a new function** ← **Via Editor**.
2. الاسم: `admin-members` (بالضبط).
3. امسح الكود الافتراضي والصق محتوى `supabase/functions/admin-members/index.ts`.
4. اضغط **Deploy**. (مفاتيح الخادم تُحقن تلقائيًا ولا تكتبها في أي مكان. وإبقاء Verify JWT مفعّلًا.)
5. افتح `check.html` وتأكد من ظهور ✅ بجانب admin-members.

## تفاصيل المهام والمواعيد (المرحلة D)
- اضغط على أي مهمة أو موعد أو جلسة (الرئيسية، المهام، الأجندة، المواعيد، يوم المحكمة) لتفتح نافذة التفاصيل.
- النافذة: التفاصيل، تسجيل النتيجة، التأجيل مع سجل (من/إلى/السبب/بواسطة/متى)، وسلسلة تعليقات.
- التعليقات سجلات مستقلة (`comments`) فلا يضيع تعليق عند تعديل جهازين لنفس المهمة. الموكل لا يرى إلا ما عُلِّم «يظهر للموكل».
- حد معروف: التأجيل والنتيجة داخل سجل المهمة/الموعد نفسه، فإن أُجِّلت المهمة نفسها من جهازين قبل المزامنة يغلب آخر كاتب على سجل التأجيلات.
- اختبارات Node: `for t in tests/*.test.js; do node $t; done`

## المكتبة القانونية (مضافة)
- المجلد `library/laws/` يحتوي على **273** نصاً قانونياً مصرياً (HTML بترميز UTF-8).
- `library/catalog.js` فهرس التصنيفات والعناوين.
- `library/search-index.js` فهرس نصي للبحث الكامل داخل القوانين.
- من داخل التطبيق: قسم **المكتبة** → تصفح حسب التصنيف أو ابحث في العناوين والنص.
- متاحة لكل المستخدمين النشطين (مدير / محامٍ / موكل حسب الصلاحيات).
